## Timing

| Message | When |
|---|---|
| Application submitted | Day 0 |
| Cold note to hiring manager (2) | Day 0–1, alongside the application |
| Referral request (3) | Before applying, if you have a connection |
| Follow-up (4) | Day 7. Once only. |
| Thank-you (5) | Within 24h of every interview, to every interviewer |
| Post-rejection (6) | Within 48h |

Log every one of these in `applications.csv` — `next_action` and `next_action_date` exist
so nothing goes cold by accident.
